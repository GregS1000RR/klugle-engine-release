# Klugle Engine — distribution

Dépôt de **distribution** de l'extension WordPress Klugle Engine.

Il ne contient pas le code source du projet : uniquement le manifeste de mise à jour
lu par les installations existantes, et les archives d'installation attachées aux
[Releases](https://github.com/GregS1000RR/klugle-engine-release/releases).
